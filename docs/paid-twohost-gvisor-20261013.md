The test itself proves the original Vault-paid session wrote application state; the authenticated owner opted into a lease-bound 30-second host notice; the timer-driven watchdog stopped the source Cell before the controller settled it; a Cyst-backed checkpoint completed before the notice deadline; and a separately funded run on the second HostKit restored the exact bounded state. It also rejects agent-side opt-in, modified owner budget/deadline, late signed cleanup evidence, a second target claim, and changed restore identity. A deliberately lost target command response replays the original journaled command without re-execution. After stopping both target runs, the test advanced its **local** chain to the receipt hour and verified each of the three runs completed with a settlement transaction and `charged + refunded = reserved ceiling`.

The acceptance daemon had zero containers afterward. All eight checked preexisting Enclave/Telomere services remained active. The independent fixture version of this same test passed locally on Windows after the final settlement assertions; TypeScript typecheck passed. The source and target HostKits were distinct identities on **one VPS**, so this does not prove recovery after physical host loss, process/GPU migration, confidentiality of the plaintext HostKit command journal, public funded Robinhood settlement, independent S3 regions, or arbitrary NEAR GPU Cells. Final public enablement remains gated by those separate operational checks and an independent security review.
