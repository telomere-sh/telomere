# Historical backend release checkpoint, 14 October 2026

Network update, 14 October 2026: the active implementation targets Base and native Circle USDC. Earlier Robinhood/USDG evidence below remains historical and does not prove Base deployment or funded acceptance. See [the current migration record](base-usdc-migration-2026-10-14.md).

This pre-migration checkpoint evaluated the adapted Telomere backend on Robinhood Chain testnet with USDG. The active target is now Base/native USDC; current network gates are recorded in the migration document linked above. Frontend work is excluded. The [13 October scope decision](backend-scope-inference-only-2026-10-13.md) makes arbitrary GPU Cells optional while retaining managed NEAR inference and the other backend milestones. The historical full-spec percentage and its equal-weight M1–M10 denominator are in `full-spec-independent-audit.md`; the revised mandatory-scope estimate is approximately 72% (67.4–75.9%, midpoint 71.7%). This document records operational gates.

The [14 October remaining-acceptance list](release-blockers-2026-10-14.md) groups the external provider, hardware, storage and funded-chain dependencies needed to close these gates.

**Public release is blocked.** Private CPU acceptance uses isolated local contracts and a private gVisor VPS; no pilot-owner wallet transaction on Robinhood testnet has been accepted. Supplier and sealed-host admission modules do not establish operational capacity. A standalone NEAR inference-only Cell also lacks live Telomere acceptance.
