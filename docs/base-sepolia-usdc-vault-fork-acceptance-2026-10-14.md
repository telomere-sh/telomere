# Base Sepolia native USDC Vault-income fork acceptance, 14 October 2026

`npm run acceptance:usdc-vault-fork` passed on a disposable, owned Anvil fork of Base Sepolia block `48100560` (`0xaa2be95f87a4d92b8d32c1d97149034e8ba1e17a4c1c8e10472c4d58aed3bea3`). The script checked a six-hour-old historical source block `48080303` (`0x4e06d144fc22ebf92b20d04b5ba5141d0163e8ff7da3af648a74b201c9730a1e`) by EIP-1898 state reads, then rechecked the selected source and local fork. The token was Circle native Base Sepolia USDC `0x036CbD53842c5426634e7929541eC2318f3dCF7e`, not a mock or USDG facet. Observed proxy hash `0xedc5281a85c0efecd49999a1ef668390c59b88702f2d4a07029d7f5d63059d6c`, Circle implementation `0xd74cc5d436923b8ba2c179b4bCA2841D8A52C5B5`, implementation hash `0x1254951e5483b882fd5def9452f58fe786eb3380c0bf9bb2744fa21a0a97a16c`, and EIP-712 name `USDC`/version `2` matched the pinned fork candidate. These observed values are **not independent production pin approval**.

The script deployed the Platform and Vault contracts only inside the fork, funded generated local accounts by impersonating an existing USDC holder only on that fork, and tested native `transferWithAuthorization` ingress. An external payer's **1,000,001** micro-USDC payment produced an Income event, **10,001** fee units and **990,000** net units; the canonical receipt and balances agreed. The owner's **100,001** unit contribution was classified as Subsidy with zero fee. Reopening the private journal and replaying the same request reused exactly the original signed transaction bytes/hash/nonce without a second transfer.

A signature for the wrong chain domain reverted with zero logs and left token nonce, Vault reference, balances and classification unchanged. A direct token authorization executed before the Vault transaction consumed the nonce but did not credit Income or fee; subsequent retries preserved the original candidate and required reconciliation. These cases verify the configured payment path's conservation and replay behavior against actual Circle code in the local fork.

The public RPC relay allowed read-only methods only and observed **200** public read requests, **zero public transactions** and no rejected-method bypasses. It guarded **30** local mutation requests. The Anvil child, read-only relay and private store closed successfully. No personal wallet, live service, paid provider call or funded Base deployment was involved. A production rollout still needs independent code/role/anchor review, a suitable operator archive RPC, wallet funding, public-chain deployment and post-deployment acceptance.
