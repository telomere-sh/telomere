# Base Sepolia Circle USDC fork acceptance, 14 October 2026

`npm run testnet:fork` passed against a disposable Anvil fork of Base Sepolia block `48100303`, hash `0xa7c564dc8e672bd3e636b5b7afdcf0fff19899c9d8e87463ddd21485f190d89b`, read from `https://sepolia.base.org`. The script used Circle native USDC `0x036CbD53842c5426634e7929541eC2318f3dCF7e`, not a mock token. The public RPC received read-only calls only. A Blockscout holder index identified a funded account, which was impersonated and funded with ETH solely inside the owned fork. The fork process stopped and its state was discarded.

At the pinned source block, the observed token metadata was name `USDC`, symbol `USDC`, version `2`, decimals `6`, with a matching EIP-712 domain. The Circle proxy code hash was `0xedc5281a85c0efecd49999a1ef668390c59b88702f2d4a07029d7f5d63059d6c`; its Circle-specific implementation pointer resolved to `0xd74cc5d436923b8ba2c179b4bCA2841D8A52C5B5`, whose code hash was `0x1254951e5483b882fd5def9452f58fe786eb3380c0bf9bb2744fa21a0a97a16c`. These are **observed candidate pins**, not an independent approval for a production profile.

Inside the fork, the legacy escrow received actual USDC, allowed withdrawal and delegated reservation, accepted a signed relayed settlement, returned unused ceiling, rejected billing beyond an owner stop, rejected an early refund, permitted a timed permissionless refund and conserved all 5,000,000 token units. There were **zero public transactions**, **zero real NEAR inference requests**, no personal wallet and no live service mutation. This tests token/escrow compatibility and local lifecycle behavior; it does not establish funded Base acceptance, private archive-RPC history, the five-contract Platform deployment, or production authorization.
